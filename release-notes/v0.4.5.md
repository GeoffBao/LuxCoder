# Yoda v0.4.5 更新

相对 `v0.4.4`：修复 Kimi API 余额不显示与实时刷新问题，新增消息导航前进后退与缩略滚动，修复多处 UI 对齐和稳定性问题。

## Bug 修复

- **修复 Kimi API（Anthropic 协议）余额不显示** — Kimi API 余额接口已升级到 v2 格式（余额字段包在 `data` 节点下），旧解析逻辑只读顶层字段导致永远返回"未返回可用余额"。修复为同时兼容 v1/v2 两种响应格式，余额标签正常显示"账户余额 ¥xx.xx"。

- **修复余额标签错误态静默消失** — 渠道余额查询失败时标签完全不可见，用户无法感知任何异常。修复为加载中显示 `...`占位符、查询失败显示具体错误文字（如 HTTP 状态码或 API 错误信息），不再静默隐藏。

- **修复看板任务侧边栏子会话计数错误** — 委派（delegate）展开的子会话被扁平化为同层节点导致计数偏大。修复层级结构以正确反映父会话下的真实子会话数量。

- **修复新建工作区顶置会话跨区泄露** — 在新工作区创建首个会话时，其他工作区已置顶的会话错误地出现在新工作区侧边栏中。

- **修复 Skills 分组残留旧品牌名** — 移除设置页面 Skills 卡片上遗留的旧品牌分组文字。

- **修复标题栏导航控件与 macOS 红绿灯对齐** — 导航按钮（前进/后退）位置与 macOS 窗口红绿灯控件未对齐，视觉上偏移。

## 新功能

- **消息导航前进后退** — 新增 Tab 级前进后退导航，支持 `⌘[` / `⌘]` 快捷键，可在当前会话的浏览历史中快速跳转。

- **消息导航缩略滚动** — 消息区左侧新增 wave 缩略卡片导航条，支持滚轮快速浏览和跳转到会话中的任意位置。

- **渠道余额实时刷新** — Agent 每次回答结束后自动刷新渠道余额标签，无需手动重新打开模型选择器，Kimi API / Kimi Coding Plan / DeepSeek 等所有支持余额查询的渠道同步生效。

## 优化

- 余额标签货币符号与文案对齐 DeepSeek 风格：`$` → `¥`、`可用余额` → `账户余额`、统一 `Kimi API 账户余额`。
- Claude Pro/Max 订阅渠道无余额查询 API，标签显示 `⚠`（hover 提示请在 Claude Code 中运行 `/usage` 查看）。
- 折叠按钮视觉效果对齐：展开时在侧栏红绿灯行右端，收起时在 TabBar 最左侧。
- 教程资源 URL 迁移到独立 `tutorial-assets` Release，简化主 Release 包体积管理。

## macOS 打开说明（重要）

当前 Release **未配置 Apple Developer ID 签名/公证**。从浏览器下载后，macOS Gatekeeper 可能误报：

> "Yoda" is damaged and can't be opened.

**这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/Yoda.app
open /Applications/Yoda.app
```
