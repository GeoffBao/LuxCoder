# LuxCoder v0.5.1 更新

相对 `v0.5.0`：修复 Git 分支/Worktree 授权链路失效与 Excalidraw 画板数据丢失问题，改进 Claude Pro/Max 订阅登录的稳定性与身份展示。

## Bug 修复

- **修复 Git 分支/Worktree 列表自 v0.5.0 起持续静默失败** — 会话的 Git 工作目录未正确解析到授权根目录，导致新会话的分支列表加载、创建 Worktree 一直因"无权访问"而失败且没有任何错误提示。现已修复授权链路，同时补全了 Worktree 生命周期管理：删除会话时自动清理对应 worktree（多会话共用时跳过）、创建时自动排除 Git dirty 检测干扰。
- **修复 Excalidraw 画板保存后无法再保存** — 文件重名追加后缀或非法字符清洗后，未把落盘真实标题同步回界面状态，导致下次保存被误判为"改名"进而报错。
- **修复 Excalidraw 画板退出未保存导致数据丢失** — 关闭窗口/切换视图时的保存时序存在竞态，现已改为持续缓存最新画布快照并在退出前同步落盘，覆盖应用整体退出场景。
- **修复 Excalidraw 画廊右键重命名输入框瞬间失焦** — 菜单焦点恢复与重命名输入框获焦存在竞态，导致刚点击重命名输入框就消失。
- **修复 Excalidraw 编辑画布后返回画廊缩略图/内容不同步** — 返回画廊时保存尚未落盘就已读取旧文件，现已改为等待保存完成后再切换视图（返回按钮显示加载状态）。
- **修复 Excalidraw 画廊卡片操作菜单点击无反应** — 右键菜单/悬浮操作按钮被应用外壳遮挡。

## 优化

- **Claude Pro/Max 订阅登录更稳健** — 刷新 token 的过期缓冲从 60 秒提前到 5 分钟，降低边界过期导致请求失败的概率；登录后 Badge 展示账号邮箱与所属组织身份信息。
- **Git 分支选择器重构** — 由独立搜索框 + 原生下拉改为统一的 Popover + 搜索下拉；新建分支从裸文本输入改为按钮 + 说明 + 可编辑 chip，Local 模式也补齐了新建分支入口。
- Diff 面板自动接入会话已选定的 Worktree 上下文，不再需要手动重新选择对比分支。

## macOS 打开说明（重要）

当前 Release **未配置 Apple Developer ID 签名/公证**。从浏览器下载后，macOS Gatekeeper 可能误报：

> "LuxCoder" is damaged and can't be opened.

**这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/LuxCoder.app
open /Applications/LuxCoder.app
```
