# MyYoda v0.7.1 更新

## 品牌视觉：应用图标全面替换为 mymind 素材

- **应用图标（大图标）**：Dock / 任务栏 / 安装包图标替换为 mymind 当前默认的毛绒橙色小人图标，全新视觉。
- **托盘小图标**：替换为 mymind 的 MenuBarIcon 指南针线稿，并去掉了图标生成脚本对 rsvg-convert 的硬依赖（未安装 librsvg 的机器也能正常生成图标）。
- **标题栏 / 启动闪屏 mark**：替换为 mymind 指南针线稿的白色版本。
- **移除「品牌 Logo 下载」功能**：设置页中的 Logo 变体下载入口已删除，相关资源与脚本一并清理（本地原始图标已备份到桌面）。

## 修复

- **ChatGPT 订阅（Codex）/ xAI 登录卡"等待授权完成…"转圈**：登录成功后 UI 状态只在 `finally` 里复位，后续拉取模型 / 创建渠道任一挂起就会导致转圈卡死；改为拿到凭据后立即复位状态，并为主进程 OAuth token 交换增加 5 分钟超时兜底，避免受限网络下永久挂起。

## macOS 打开说明（重要）

当前 Release **未配置 Apple Developer ID 签名/公证**。从浏览器下载后，macOS Gatekeeper 可能误报：

> "MyYoda" is damaged and can't be opened.

**这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/MyYoda.app
open /Applications/MyYoda.app
```
