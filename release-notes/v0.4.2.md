# LuxCoder v0.4.2 更新

相对 `v0.4.1`：看板卡片支持重命名/归档/删除，侧边栏主子任务会话层级展示统一，修复标题中段重新生成从未生效、用户短消息气泡意外换行等问题。

## 新功能

- **看板卡片新增重命名/归档/删除** — 右键（或触控板双指点击）任务卡片，菜单在原有「编辑任务」基础上新增「重命名」「归档 / 取消归档」「删除」，与侧边栏会话列表操作一致；归档/删除只作用于卡片本身对应的会话，不影响其展开的子任务。

## Bug 修复

- **会话标题中段重新生成从未生效** — 长会话多次话题跳转、多次 `/compact` 后，标题本应在消息数达到一定节点时自动刷新，但因消息格式判断逻辑的缺陷，该机制自上线后从未真正触发过；标题会一直停留在最初一条消息的截断文本上。
- **用户短消息气泡意外换行** — 修复气泡宽度计算导致的短消息强制换行问题。
- **侧边栏主子任务会话层级不统一** — 编排任务的子任务会话在日期、项目、状态等不同分组视图下展示规则不一致，部分视图会漏掉或错误过滤子任务；统一为「主任务 + 缩进子任务」的层级展示，运行中/阻塞的任务族默认展开。

## macOS 打开说明（重要）

当前 Release **未配置 Apple Developer ID 签名/公证**。从浏览器下载后，macOS Gatekeeper 可能误报：

> "LuxCoder" is damaged and can't be opened.

**这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/LuxCoder.app
open /Applications/LuxCoder.app
```
