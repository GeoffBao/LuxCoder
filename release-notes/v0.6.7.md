# LuxCoder v0.6.7 更新

## 新功能

- **EventKit 集合双向同步（macOS）**：日历 / 提醒事项支持连接系统集合后双向同步——你明确选择的系统日历或列表会导入 LuxCoder，在 LuxCoder 内修改或删除可写的 Calendar / Reminder 项都会回写系统；系统端变更也会被监听并同步回来。删除冲突（系统端已删 / 有新修改）会要求你确认「保留 LuxCoder」或「保留系统」，避免静默覆盖。设置里也提供「受管目标」模式：选定一个系统集合作为发布目标，把现有 LuxCoder 项目持续发布过去，受管目标与外部连接两套机制互斥，不会重复管理同一集合。
- **任务家族会话面板**：任务进入「任务家族」会话，与 craft 心智对齐；看板入口按钮改为带文案胶囊样式，更直观。
- **侧栏「未发送草稿」找回**：此前未发送消息的草稿会话会被过滤掉，点「新会话」/ Cmd+N 会把刚输入的内容「顶没」；现在侧栏新增「未发送草稿」区块，新会话按钮在存在可回收草稿时优先跳转回去，toast 附「新建」按钮可强制新建，不再丢失输入。
- **欢迎页「配置 AI 渠道」入口**：新用户首次打开欢迎页即可直接跳转配置 AI 渠道（可跳过），减少上手摩擦。

## 修复

- **EventKit marker 识别失效**：品牌适配时 URL scheme 前缀写成了 proma://，导致 LuxCoder 自己写入的 marker 永远无法被识别，受管日程退化成需手动确认的冲突；已修正为 luxcoder://。
- **Pi Agent 的 Todo / 日程工具未接线**：Planning 工具集（Todo/日程/分组/标签/提醒 CRUD）此前定义完整但从未注入 Pi Agent，导致 Agent 无法使用这些本地能力；现已接线并始终可用。
- **Git 分支名与同名 tag 冲突**：存在同名 tag 时 Local 模式报 "a branch is expected, got 'refs/heads/main'"，会话上下文准备失败；改为从完整 ref 路径截取短名，并新增回归测试。
- **Home 模式新会话工具面板永远「加载中…」**：工具列表只在打开过设置面板时才填充；新增全局初始化在启动时加载并订阅 chat-tools.json 热刷新，已启用工具（记忆/联网搜索等）正常生效。
- **任务/日程工具权限策略**：补齐受管同步目标与外部连接的对称互斥校验与 UI 过滤，同一个系统集合不会再被两套机制同时管理。

## 界面与体验

- **Haze 主题暖色玻璃提亮**：左侧导航栏、顶部标题/路径栏、右侧「相关文件」面板与输入框改为更亮更透的暖色玻璃，背景遮罩减半，壁纸自然透出；内容区与弹层形成「透 → 实」的层级过渡。
- **基础动效 / 按压 / 色彩规范化**：全端统一动效时长 token，补齐菜单项、设置导航等关键交互的按压反馈，错误/危险状态统一收敛为主题语义色（destructive），并新增「减弱动态效果」系统偏好支持。
- **新会话空状态轻量化**：移除 hero 图外的模糊氛围背景层，保留清晰前景图 + 问候语 + 一行功能提示，更简洁。
