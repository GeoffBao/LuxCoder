# LuxCoder v0.6.6 更新

## 新功能

- **文件预览支持 HTML（.html/.htm）**：预览面板可直接渲染 HTML 页面效果——页面内相对路径资源（CSS / JS / 图片）自动解析补齐，支持脚本运行以完整呈现现代页面；安全沙箱防止页面导航走主应用，上级目录越界访问被协议拒绝。
- **文件预览支持视频播放（.mp4 / .webm / .mov 等）**：内联播放视频并可拖动进度条——底层本地文件协议新增 HTTP Range 分段响应（206），大视频按需加载、seek 流畅；HTML 页面内嵌的视频引用同样支持。
- **PDF 预览顺带提速**：底层协议 Range 支持让 PDF 预览从「全量加载」变为「按需分页」，大 PDF 打开更流畅。

## 修复

- **haze / scenic 玻璃主题下项目选择器面板顶部点不动**：新会话空状态里「选择/新建项目」面板最上面的几个项目无法点击，根源是玻璃主题的 backdrop-filter 创建了层叠上下文、把非浮层面板困在低层；已修复层级关系，面板所有项目均可正常点击。
