# LuxCoder v0.6.9 更新

## 新功能

### CodeClaw 桌宠全面升级（v2 / v2.1 / v2.2）

- **完整动画状态**：细粒度消费各主题全部素材——working / thinking / juggling / attention / error / notification 等 16 个桌面状态 + 9 个 Mini 状态，由 Agent 任务、工具调用、上下文压缩、错误、权限请求等事件自动驱动，不再只显示 5 个阶段。
- **眼动追踪**：桌宠眼球跟随鼠标光标实时转动（多层 trackingLayers），Clawd / Calico 等多主题支持。
- **睡眠与唤醒**：鼠标长时间不动（20s）且无活跃会话时自动进入打哈欠 → 小睡 → 沉睡序列，恢复活动播放起床动画（waking，保持 wakeDuration 不会一闪而过）。
- **点击反应**：单击打开对应会话、双击打开主窗口、快速连点 3 次触发 annoyed 反应、拖拽移动（拖拽贴边自动进入 Mini 模式）。
- **Mini 模式**：贴边吸附只露 25px + 悬停探出 + 点击退出，播放 mini 素材；退出后恢复记忆位置。
- **权限气泡**：Agent 触发权限请求 / AskUser / 退出计划时，桌宠弹出审批气泡卡片，可直接在主窗口完成审批（respondPermission / respondAskUser / respondExitPlanMode）。
- **右键菜单**：桌宠上右键弹出原生菜单——Mini 开关、主题单选、尺寸单选、免打扰 checkbox、音效 checkbox、打开 LuxCoder。
- **尺寸档位 S / M / L**：三档尺寸一键切换（s 0.72x / l 1.28x），窗口中心保持。
- **免打扰（DND）**：开启后权限 / 提问 / 退出计划事件静默处理（保持 running 但不弹气泡），适合演示或专注场景。
- **音效反馈**：任务完成播放 complete、气泡出现播放 confirm（10s 冷却防打扰；DND / 关闭音效时静音）。
- **会话 HUD**：桌宠右上角展开轻量会话面板，展示最近会话并可点击直达，替代独立 Dashboard 窗口。
- **系统托盘控制**：托盘菜单集成桌宠控制项——启用开关 / Mini / 主题 / 尺寸 / 免打扰 / 音效，与右键菜单共用同一配置源。

### 其他新功能

- **新会话空态补全引用引导**：Agent 模式新会话空态功能提示补全「引用会话 (&)」「待办/日程 (～)」两项，与输入框占位符语法一致。

## 修复

- **Clawd 主题显示错误页**：桌宠眼动追踪原用 `<object>` 加载 SVG，打包版 file:// 协议下加载失败显示 "this page ... error on line" 错误页；改为 Vite `?raw` 内联 SVG（无运行时文件加载、可直接 querySelector 操作眼动元素），Clawd / Calico 主题不再出现错误页且眼动正常，取不到内联素材时自动回退 `<img>`（不眼动）。
- **ProjectContextPicker inline 变体点击无反应**：项目选择器面板改用 Radix Popover Portal（z-[9999]）替代手写 absolute + 全屏遮罩，修复 inline 变体断行 / overflow 裁切 / 面板被 AppShell 中间容器盖住导致点击项目名"没反应"。
- **Chat 迁移到 Project 保持当前空间**：会话迁移到项目时目标空间优先使用当前空间（`currentAgentWorkspaceIdAtom`），不再默认落到列表第一个空间（可能是历史 / 测试空间），避免迁移后新会话建到错误空间且持久化配置被切走。

## 界面与体验

- **统一 Code/Home 术语为 Project/Chat**：系统提示词、内置 Prompt、教程（tutorial.md / tutorial-service）、设置页、折叠侧栏 aria/tooltip、Skills/MCP 空态等用户可见文案统一为「Project / Chat 模式」。
- **CodeClaw 主题素材质量修复**：内联 SVG 强制容器内缩放（素材自带 width/height 不再溢出 220×220 桌宠窗口）。

## macOS 打开说明（重要）

当前 Release **未配置 Apple Developer ID 签名/公证**。从浏览器下载后，macOS Gatekeeper 可能误报：

> "LuxCoder" is damaged and can't be opened.

**这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/LuxCoder.app
open /Applications/LuxCoder.app
```
