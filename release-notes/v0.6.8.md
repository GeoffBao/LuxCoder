# LuxCoder v0.6.8 更新

## 新功能

- **Project 模式空态问候语绑定项目**：新会话问候语中的项目名可点击切换（复用项目选择器），默认绑定最近工作的项目；整个工作区首次新建会话时会引导创建项目，之后新会话自动继承最近项目，减少重复选择。
- **任务家族会话面板**：任务进入「任务家族」会话，与 craft 心智对齐；看板入口按钮改为带文案胶囊样式，更直观。
- **侧栏「未发送草稿」找回**：此前未发送消息的草稿会话会被过滤掉，点「新会话」/ Cmd+N 会把刚输入的内容「顶没」；现在侧栏新增「未发送草稿」区块，新会话按钮在存在可回收草稿时优先跳转回去，toast 附「新建」按钮可强制新建，不再丢失输入。
- **欢迎页「配置 AI 渠道」入口**：新用户首次打开欢迎页即可直接跳转配置 AI 渠道（可跳过），减少上手摩擦。

## 修复

- **Git 分支名与同名 tag 冲突**：存在同名 tag 时 Local 模式报 "a branch is expected, got 'refs/heads/main'"，会话上下文准备失败；改为从完整 ref 路径截取短名，并新增回归测试。
- **Home 模式新会话工具面板永远「加载中…」**：工具列表只在打开过设置面板时才填充；新增全局初始化在启动时加载并订阅 chat-tools.json 热刷新，已启用工具（记忆/联网搜索等）正常生效。
- **空状态多余背景层**：移除 hero 图外的模糊氛围背景层，保留清晰前景图 + 问候语 + 一行功能提示，更简洁。

## 界面与体验

- **顶栏模式栏收敛命名 Project | Chat**：左边 Project（Agent 深度工作：工作区 / 项目 / 看板 / MCP / Skills），右边 Chat（轻量多 Provider 对话），布局与旧 Home|Code 对调。
- **Excalidraw 画布 / Yoda 知识库入口迁入 Project 模式**：入口从 Chat 侧移到 Project 侧；「Excalidraw 画板」更名为「Excalidraw 画布」。
- **Haze 主题暖色玻璃提亮**：左侧导航栏、顶部标题/路径栏、右侧「相关文件」面板与输入框改为更亮更透的暖色玻璃，背景遮罩减半，壁纸自然透出；内容区与弹层形成「透 → 实」的层级过渡。
- **基础动效 / 按压 / 色彩规范化**：全端统一动效时长 token，补齐菜单项、设置导航等关键交互的按压反馈，错误/危险状态统一收敛为主题语义色（destructive），并新增「减弱动态效果」系统偏好支持。
- **Chat 欢迎页 hero 图焕新**：欢迎页 hero 图换成蜘蛛侠图。
- **命名方案统一：工作区→空间、项目→工作区**：AgentWorkspace 用户可见文案统一为「空间」，craft Project 用户可见文案统一为「工作区」；新建工作区支持「选文件夹即建」并自动取目录名；会话标题增加面包屑（工作区名 · 路径）。

## macOS 打开说明（重要）

当前 Release **未配置 Apple Developer ID 签名/公证**。从浏览器下载后，macOS Gatekeeper 可能误报：

> "LuxCoder" is damaged and can't be opened.

**这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/LuxCoder.app
open /Applications/LuxCoder.app
```
