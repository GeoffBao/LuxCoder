# LuxCoder v0.6.1 更新

## 项目与看板

- **隐藏容器 Project**：每个工作区自动维护「首页工作区」「临时会话」两个系统 Project，不可删除/重命名/归档。未绑定真实 Project 的 Code 会话（含历史会话）在看板上自动归类展示为「临时会话」，不再和真实项目混在一起，也不影响会话原有的独立工作目录。
- **看板/项目选择器更干净**：侧边栏项目子分组、看板项目筛选器、任务编辑器、Todo/日程的「关联项目」选择器统一排除上述系统 Project，只展示你自己创建的项目。

## Task 日历

- **日程可关联项目**：新建/编辑日程时新增「关联项目」选择，日历事件也能像 Todo 一样归属到具体项目，方便按项目回顾安排。

## 文件与 Outbox

- **Outbox 按类型分组展示**：会话产出目录（Outbox）在右侧「相关文件」中按文档 / 图片 / 数据 / 演示 / 代码 / 其他自动分组，不需要维护分类目录，适配内容创作、设计、产品、研发等各类使用场景。

## 命名与设置整理

- 统一「Yoda 记忆」「Yoda 知识库」「Yoda 插件」命名体系，收纳进设置面板，跨 Home / Code 模式共享。
- 设置面板新增「工作区」管理入口。
