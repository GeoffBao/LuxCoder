# LuxCoder v0.6.3 更新

## Agent 与 Skill

- **工作区批量导入 Skill**：从其他工作区勾选多个 Skill 一键批量导入到当前工作区，自动过滤已安装同名项，导入完成 toast 汇总「成功 / 跳过 / 失败」；同一 Skill 并发导入自动串行，重复导入安全跳过，失败不残留残缺目录。
- **企业组织 Skills 分发**：新增企业版 Skills 分发服务端（`apps/server/`，注册/登录/JWT + 组织与成员管理 + Skills 仓库与分发 API + API Key 认证 + Docker 部署）；客户端新增「组织 Skills」页与组织连接/导入/更新，支持账号与 API Key 双模式认证。
- **社区市场（n-skills）**：接入 n-skills 社区市场，支持浏览与一键安装社区 Skill，兼容 Claude Code plugin 嵌套 skill 目录结构。
- **非 Git 文件变更展示**：Agent 在非 Git 目录（如 Downloads、普通文件夹）写入文件后，右侧文件变更面板新增「本会话文件变更」分组，按本轮 / 更早划分，点击可直接打开纯文件预览；Git 仓库会话仍走原 Git diff 展示。
- **Markdown 编辑器状态保留**：编辑文件后切换 Tab / 保存 / 失焦再回来，光标位置、滚动位置与未保存草稿完整保留，不再跳回开头。

## 语音输入

- **听写输出上下文冻结**：录音期间修改输出模式设置不影响本次听写去向，文本按开始时的设置路由；修复取消 / 提交后迟到事件重新激活会话的竞态。
- **输入框回填回执**：目标输入框卸载 / 失效时如实提示并回退复制到剪贴板，不再误报「已写入」。

## 交互与界面

- **Mention 引用触发修复**：URL 中的 `/`、`#`、`@`、`&` 不再误触引用菜单；粘贴内容不会误弹引用建议。
- **图片 @ 引用点击预览**：消息与输入框中的图片引用 chip 支持点击直接打开图片预览。
- **Todo 描述保存状态修复**：切换 Todo 后「保存中 / 已保存」状态不再残留到上一个任务。
- **Windows 设置窗口控制**：修复 Windows 上设置窗口最小化 / 最大化 / 关闭按钮被标题栏拖拽区域遮挡无法点击的问题。
- **更新器改进**：统一发布渠道并内嵌更新日志展示。
