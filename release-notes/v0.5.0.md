# LuxCoder v0.5.0 更新

v0.5.0 是一次重大版本：信息架构全面升级、新增 Excalidraw 画板、Git 分支执行隔离、Agent 体验修复。

## Excalidraw 画板 — 即时手绘白板

侧栏新增「Excalidraw 画板」入口，无需离开 LuxCoder 即可创作手绘风格图表。

- 画板画廊：卡片网格展示所有画布，含 SVG 缩略图预览
- 全功能编辑器：集成 Excalidraw 手绘引擎，支持矩形/椭圆/菱形/箭头/文字/图片等所有元素类型
- 自动保存：每 60 秒自动落盘，Cmd+S 手动保存
- 导出：可将画布导出为 .excalidraw 文件到任意路径
- 画廊管理：右键菜单支持重命名与删除画布
- 存储：文件按 Workspace 隔离，存于 `<workspace>/.luxcoder/excalidraw/`

## 信息架构全面升级

对 LuxCoder 的信息组织方式做了系统性重构：

- **Task 成为独立实体** — Task 不再必须绑定 Project。Workspace Task 和 Project Task 两种形态并存，每个 Task 拥有稳定的身份标识和 Run 历史。
- **全新任务看板** — 四列看板（待办 / 进行中 / 待验收 / 已完成），任务创建使用统一渐进式 Composer。
- **Labels 标签系统** — Workspace 级别的标签管理，Task 和会话均可打标签组合筛选。
- **Project 页面升级** — 独立资料页含知识库、资产、会话历史、设置四个 Tab。
- **Workspace Context** — Agent 技能「记忆」更名为 Workspace Context，承载跨项目规则与长期偏好。
- **Expert 工作区隔离** — Expert 身份核全局共享，Skill/MCP 绑定按 Workspace 隔离。

## Git 分支选择与 Worktree 执行隔离

Draft Composer 顶部新增 `Project | Local/Worktree | Branch` 上下文选择，Agent 可在独立 worktree 中执行任务，与当前工作区完全隔离。

## Agent 体验修复

- 修复对话页左侧大空白布局问题（assistant 头像 gutter + TabBar 原生全屏误判）
- 修复 Agent 标题早期不纠偏问题，首轮对话完成后即触发标题重新生成
