# LuxCoder v0.6.4 更新

## 修复

- **孤儿工作区清理误删 Project/画板数据（重要修复）**：设置 → 磁盘管理 → 清理孤儿工作区文件，此前会把全部 Project（config.json / MEMORY.md / assets / 托管工作目录）和 Excalidraw 画板文件当成已删除会话残留的垂圾一并物理删除；本版本已修复检测边界，不会再误删。**注意：此前若已经点过该清理，已删除的数据无法通过升级恢复。**
- **原生任务快捷入口位置修复**：Agent 会话列表增量刷新链路的收尾修正。

## Agent 与 Skill

- **预置 dashi-ppt 为默认 Skill**：内置随包分发，创建横向翻页网页 PPT（WebGL 背景、章节幕封、数据大字报等模板）无需额外安装。
- **社区 Skills / 组织 Skills 持续完善**：细节修复与命名统一。

## 效率与体验

- **原生任务快捷入口**：macOS Dock 右键菜单、Windows Jump List、全局快捷键 `Cmd/Ctrl+Shift+T`，可直接跳转到 Todo/规划面板。
- **原生启动闪屏页**：应用启动不再依赖 Renderer 加载完成才显示界面，加载失败自动降级到错误页，避免白屏。
- **Agent 会话列表响应更快**：会话流式完成后只增量更新单条会话，不再每次全量刷新列表。
- **macOS 日历/提醒事项单向同步**：Todo/规划面板内容可同步到系统 Calendar / Reminders（macOS）。

## 模型

- **DeepSeek V4 推理强度映射修复**：Pi 运行时下 DeepSeek V4 的 reasoning effort 设置生效。
