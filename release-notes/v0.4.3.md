# LuxCoder v0.4.3 更新

相对 `v0.4.2`：Scratch Pad 图片体验一揽子升级，新增 Git/PR 归因标识、Windows Shell 手动切换、OpenCode Go 订阅渠道，以及一批上下文用量、Pi 错误处理、侧边栏交互的修复与打磨。

## 新功能

- **Scratch Pad 图片体验一揽子改进** — 图片支持右下角拖拽缩放，宽度会持久化进 Markdown 并在重新打开时正确还原；新增 hover 工具栏，可直接复制图片到系统剪贴板、进入编辑模式或删除；单击图片可打开预览。
- **Git/PR 归因标识（LuxCoder 品牌，默认开启）** — Agent 代你创建 commit / PR 时会附加 `Made-with: LuxCoder` 标识与项目链接，避免 SDK 默认把 AI 生成的改动署名成你本人；设置 → 通用 可随时关闭。
- **Windows Shell 支持手动切换 Git Bash / WSL** — 默认策略不变（优先 Git Bash，不可用时自动回退 WSL），新增设置项可显式指定偏好 Shell，首选项不可用时仍会安全回退。
- **新增 OpenCode Go 订阅渠道** — 一次订阅接入 Grok-4.5、GLM-5.2/5.1、Kimi K3/K2.7/K2.6、DeepSeek V4、MiMo V2.5 等模型。
- **文件浏览器新增「在终端中打开此文件夹」**（macOS）— 目录右键菜单新增终端打开入口。
- **模型选择器 hover 显示当前渠道** — 同一模型配置了多个渠道时，hover 触发按钮即可确认当前实际在用哪个渠道。
- **补充新会话/新任务键盘快捷键** — 按钮 tooltip 显示对应快捷键；新增「新建任务」快捷键 `Cmd/Ctrl+Shift+N`（仅 Agent 模式）。
- **Codex OAuth 会话自动生成语义化标题**。
- **GPT-5 系列模型能力自动推断**（上下文窗口等）。
- **Pi 运行时新增会话内压缩工具**，可在当前会话中直接触发上下文压缩。

## Bug 修复

- **正文里引用本地文件的 Markdown 链接现在可点击** — 之前只有 `mention://` 协议链接会渲染成可交互 chip，普通本地绝对路径（含 `file_path:line_number` 写法）会渲染成点击无反应的死链接，现已统一识别并渲染为可跳转的文件引用。
- **Scratch Pad 复制选区到剪贴板时段落间距恢复正常单换行** — 之前复用了 Markdown 文件持久化的转换逻辑，会在段落间多插入一个空行，粘贴到其他编辑器时格式跑偏。
- **保留 Pi 终态错误发生前已生成的正文** — 修复网络/服务商错误发生前 Pi 已生成的文本被错误信息一并覆盖丢弃的问题。
- **识别 HTTP chunked/SSE 断流错误为可重试网络异常** — 流式响应中途被上游/代理断开的传输层错误，之前会被误判为「服务繁忙」且不会自动重试，现已正确分类并纳入重试与提示文案。
- **默认应用打开入口不因探测失败而消失** — 探测本机默认 App 失败或未完成时，「用默认应用打开」入口之前会整体隐藏；现在始终保留入口，探测失败时退化为通用图标 + 系统默认应用文案。
- **自定义 OpenAI 兼容渠道降级 developer 角色为 system** — 部分自定义兼容后端不支持 `developer` 角色，改用兼容性更好的 `system`；原生 OpenAI/Codex 渠道不受影响。
- **手动压缩后立即显示预估上下文用量** — 压缩完成后用量徽标之前会停留在压缩前的旧数字，直到下一轮真实用量才刷新，现在压缩完成即用预估值展示。
- **OpenCode Go 渠道 kimi-k3 模型上下文窗口推断修复** — 修复精确匹配规则遗漏导致 1M 上下文未生效的问题。
- **Excel 预览单个工作表最多显示行数从 100 提升到 200**。
- **修复子会话完成通知刷屏、侧边栏子任务展开/收起点击区域重叠、非终态 Pi 结果被误判为错误、思考模式关闭状态未保留、任务草稿未按所选模型生成、刷新时配额短暂丢失、Ark GLM-5.2 输出未限流、教程页跨视图跳转失效等问题**。
- **侧边栏「自动任务」模块改名为「Agent 自动化」** — 折叠态图标按钮、展开态模块入口、任务编辑页返回按钮三处保持一致。

## macOS 打开说明（重要）

当前 Release **未配置 Apple Developer ID 签名/公证**。从浏览器下载后，macOS Gatekeeper 可能误报：

> "LuxCoder" is damaged and can't be opened.

**这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/LuxCoder.app
open /Applications/LuxCoder.app
```
