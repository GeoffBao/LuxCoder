# Yoda v0.6.2 更新

## 主题与界面

- **主题预设与界面风格分层**：「Yoda 精选」保留「经典 / 现代」布局选择；更多预设（Craft 迁移主题）统一使用现代工作台，选择后自动切换到现代布局，避免主题与界面风格策略互相矛盾。
- **修复经典/现代主界面材质被统一**：此前主题迁移把现代玻璃材质覆盖到了经典界面，切换布局后看起来一样；现两套材质正确区分——经典保留原有几何与无模糊表面，现代使用独立面板分层与玻璃质感。
- **现代工作台框架**：现代布局下窗口四周留出外层间隙，主 / 侧面板采用独立圆角面板与分层阴影，替代贯穿全高的硬分割线，更贴近企业级 Agent 工作台形态；CRT 终端与经典布局不受影响。
- **主题选择原子持久化**：一次保存主题模式 / 界面风格 / 预设 / 界面变体，避免多个异步设置互相覆盖旧的界面风格。

## 项目文件

- **绑定 Project 后立即刷新**：新建会话选择项目后，右侧「项目文件」立即展示项目目录，不再需要等 Agent 跑完第一轮才出现。
- **项目目录不可用明确提示**：当项目工作目录被移动 / 删除 / 外接盘断开时，右侧面板显示醒目的「目录不可用」提示与原路径，并可一键前往项目设置重新关联，不再与「尚未绑定项目」混淆。
