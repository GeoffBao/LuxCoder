# MyYoda v0.4.4 更新

相对 `v0.4.3`：修复看板 AI 生成任务计划时误创建并运行子会话的问题，强化了任务生命周期三段边界；修复打包后使用指南显示为旧版 Proma 教程的问题；渠道设置新增第三方中转地址风险确认。

## Bug 修复

- **修复设置页「使用指南」显示旧版 Proma 教程** — 打包配置指向了仓库根目录 `tutorial/tutorial-v2.md`（Proma 版），导致安装 DMG 后打开使用指南看到的是 Proma 说明而非 MyYoda 使用指南。修复为打包 `apps/electron/resources/tutorial.md`（MyYoda 版）。

- **修复教程内图片全部无法显示** — 教程截图和宣传视频本地相对路径在打包后无对应的本地资源，改为上传到 GitHub Release 并通过外链 URL 引用。

- **修复教程内宣传视频无法播放** — `<video><source></video>` 格式不被 Markdown 渲染器的原生视频节点捕获，落入静态 HTML 节点后无法触发资源加载。改为 `<video src="...">` 格式，直接命中 `createMarkdownVideo` 原生 DOM 渲染。

- **修复看板「AI 生成任务计划」阶段误创建并运行子会话** — 在任务编辑器「生成初始计划」时，右侧仍显示生成中，左侧栏却已出现子任务正在运行，且最终生成失败后没有把子任务填回编辑器。根因是生成 task.yaml 草稿的 Agent 会话可以使用完整工具集（含协作子会话、创建看板任务、计划模式等），同时生成阶段在用户确认前就已把 task spec 写入磁盘。

  **修复内容：**
  - 生成计划阶段禁用所有工具调用：不暴露 MCP 服务器、协作子会话、创建任务、自动化等内置工具；即使模型尝试调用工具也会被拒绝。
  - 生成计划不再写磁盘上的 task.yaml 文件，改为通过事件直接返回可编辑计划草稿供用户预览。
  - 只有用户点击「创建」或「创建并运行」后才会正式写入任务定义并转正草稿会话。
  - 删除生成草稿时会自动清理其意外产生的子会话。
  - 生成阶段的隐藏会话不再出现在左侧栏列表中。

## 新功能

- **欢迎页新增产品宣传视频** — 新用户首次打开 MyYoda 时，欢迎页标题下方展示产品宣传视频，提供直观的功能概览。

- **渠道设置新增第三方中转地址风险确认** — 填写非官方默认的 Base URL 时，会弹出风险确认对话框，避免误填不信任的代理/中转地址导致 API Key 泄露。

## 优化

- 看板任务编排生命周期严格分为三段：生成=草稿、创建=写盘/转正、运行=创建并运行子任务，降低维护复杂度与意外副作用风险。

## macOS 打开说明（重要）

当前 Release **未配置 Apple Developer ID 签名/公证**。从浏览器下载后，macOS Gatekeeper 可能误报：

> "MyYoda" is damaged and can't be opened.

**这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/MyYoda.app
open /Applications/MyYoda.app
```
