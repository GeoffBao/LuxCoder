# LuxCoder v0.6.5 更新

## 新功能

- **项目看板自定义列**：Project 支持自定义看板列——新增 / 改名 / 改色 / 绑定工作流状态（workflow），卡片拖入自定义列后位置持久化保存，重启不丢失；删除有卡片的列时自动挪到剩余第一列。未配置自定义列的项目保持原有默认列行为不变。
- **Claude 订阅登录会话「分叉 / 回退」修复（重要）**：使用 Claude 订阅（anthropic-oauth）登录的会话，此前「分叉」和「回退到此处」会报「该 Pi 历史消息尚无 entry ID 映射」错误；本版本修正运行时字段持久化判断，存量受影响会话在下次发消息时自动纠正，两个功能恢复正常。

## 界面与体验

- **新会话空状态升级为个人版视觉**：去除企业版品牌形象，改为沉浸式 hero 大图 + 个性化时段问候 + 一行轻量功能提示（Chat / Agent 模式分别展示对应能力，如拖拽上传、@ 引用文件、# 调用 MCP、/ 使用 Skill），整体更简洁现代，对齐个人用户定位。
