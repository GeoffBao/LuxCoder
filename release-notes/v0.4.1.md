# LuxCoder v0.4.1 更新

相对 `v0.4.0`：修复 Claude Pro/Max 订阅登录在正式打包环境下无法完成的问题，看板卡片编辑/时间戳/新建任务体验对齐 craft-agents-oss，多项界面细节调整。

## Bug 修复

- **Claude Pro/Max 订阅登录无法完成** — 原实现 spawn 打包的 `claude` 二进制走 `setup-token` 子命令，该子命令是纯交互式 TUI：正式打包环境没有 controlling terminal 时会静默挂起（开发模式下"能登录"只是碰巧继承了开发终端）。改为原生实现 OAuth Authorization Code + PKCE 流程，不再依赖交互式子进程；同时补上 refreshToken 自动续期，登录凭据不再像旧版那样只能撑约 1 年后手动重登。
- **Claude 订阅渠道发消息报错** — 消息发送前解析鉴权信息的分支之前漏了 `anthropic-oauth` 渠道，会把整段加密凭据 JSON 当 token 传给 SDK；本次一并修正。
- **看板卡片右键/双指菜单点不出来** — `ContextMenuContent` 默认层级在看板这层会被 app-shell 更高层级的元素盖住，菜单其实弹出了但看不见；补上层级覆盖。
- **看板卡片编辑按钮只在部分卡片出现** — 之前编辑仅对已绑定 task spec 的卡片开放；侧边栏「新会话」创建的普通会话卡片没有编辑入口。对齐 craft：任何卡片都能编辑，没有 task spec 时编辑器用卡片当前标题/模型起草新表单，保存即把普通会话升级成任务。

## 新功能

- **看板卡片新增消息数徽标** — 卡片右下角时间戳旁新增消息数量徽标（对齐 craft），历史卡片首次加载时一次性补齐计数。
- **看板新建任务改为两层模型** — 列顶部常驻单行标题输入框，回车直接建一个普通会话落到待办列；「详细设置」展开成原有完整任务表单（目标/项目/子任务 DAG）。

## 其它调整

- 悬浮用户消息条字号/间距略微调大。
- 下线外观设置里的应用图标自定义功能（渲染层、IPC、主进程 dock 图标应用逻辑一并清理）。

## macOS 打开说明（重要）

当前 Release **未配置 Apple Developer ID 签名/公证**。从浏览器下载后，macOS Gatekeeper 可能误报：

> "LuxCoder" is damaged and can't be opened.

**这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/LuxCoder.app
open /Applications/LuxCoder.app
```
