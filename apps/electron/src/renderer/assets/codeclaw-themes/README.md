# CodeClaw third-party themes

This directory vendors pet theme metadata and artwork from `clawd-on-desk` at the user's explicit request.

Source: https://github.com/rullerzhou-afk/clawd-on-desk
License: AGPL-3.0-only. See `LICENSE.clawd-on-desk.txt` and `NOTICE.clawd-on-desk.md`.

LuxCoder's built-in `lux` theme remains original. The vendored `clawd`, `calico`, and `cloudling` themes use upstream SVG/APNG/theme.json assets and must preserve the upstream license/notice when distributed.
